# X Helper · Chrome 扩展版

X Helper 的桌面浏览器版本：统计 x.com 使用时长，抓取账号粉丝 / 关注 / 帖子数快照，每晚 23:05 推送当日总结。数据只存浏览器本地（`chrome.storage.local`），不向外发送。

## 安装

1. 还原图标（仓库里图标以 base64 文本存放，clone 后运行一次）：
   ```bash
   bash extension/tools/restore-icons.sh
   ```
2. 打开 `chrome://extensions`，右上角打开"开发者模式"
3. 点"加载已解压的扩展程序"，选择 `extension/` 目录
4. 登录 x.com 后正常使用即可

## 功能

- **使用时长统计**：x.com 标签页处于前台可见时，每 10 秒计一次；切走即停
- **账号快照**：打开自己的 X 个人主页时，自动解析粉丝 / 正在关注 / 帖子数并落盘
- **23:05 日报**：系统通知推送当日使用时长、打开次数、粉丝变化、新增发帖
- **AI 评论候选**：在任意推文的回复框里点右上角"✦ AI评论"，先由 Jev 判断推文意图并选定最合适的回复策略，再由 Grok 定向生成候选，点一条直接填进回复框
- **统计弹窗**：点工具栏图标查看今日使用、24 小时分布、账号数据、最近 7 天（跟 App 同款浅色 UI）
- **中英双语**：跟随浏览器语言（中文/英文）

## AI 评论候选的工作原理

流程：**Jev 意图判断 → Grok 定向生成**。

1. **Jev 先行**（一次调用三问）：推文适合哪种回复策略（幽默接梗 / 观点补充 / 友好互动 / 提问请教 / 别回）？值得回吗？有引战风险吗？值得回且安全才自动生成；风险高的会先警告，建议别回的直接劝退并给出"仍要生成"的手动选项
2. **Grok 生成**：按 Jev 选定的策略定向生成 5 条候选

Jev 走 TypeSafe 官方 API（`api.typesafe.ai/v1/systemone`），需要你自己的 `TYPESAFE_API_KEY`，在插件弹窗底部设置里粘贴保存，只存浏览器本地。Grok 部分直接调用 X 内置接口（`grok.x.com/2/grok/add_response.json`），借用浏览器已登录态（cookie + CSRF + 页面请求里嗅探到的签名），**不需要 API key**，`isTemporaryChat=true` 不污染你的 Grok 对话历史。

X 的接口需要 `x-client-transaction-id` 签名，插件不会自己算，而是**偷 X 自己的**：

1. 你去 `x.com/i/grok` 随便发一条消息
2. 插件在页面层嗅探到这次请求的签名，缓存 1 小时
3. 之后点"✦ AI评论"直接用缓存签名生成

如果点生成时提示去发消息，照做一次就行。签名过期（X 更新导致 404）时会自动作废并提示刷新重试。

## 文件

- `manifest.json` — MV3 配置
- `background.js` — 计时、快照落盘、23:05 闹钟与通知
- `content.js` — 跑在 x.com 页面里：心跳、识别登录账号、主页数据解析
- `popup.html` / `popup.js` — 统计弹窗
- `_locales/` — 中英双语文案
- `icons/` — 插件图标

## 隐私

扩展只请求 `x.com` / `twitter.com` 的页面读取权限（用于计时和解析你自己的主页数据），所有数据存在本地 30 天自动滚动清理。不含任何上报、统计或远程请求代码。

## 已知限制

- X 网页 DOM 结构经常调整，账号数据解析带多重降级：抓不到时静默跳过、保留上次快照
- 计时粒度 10 秒；离开电脑但页面开着会继续计时（与 App 版行为一致）
